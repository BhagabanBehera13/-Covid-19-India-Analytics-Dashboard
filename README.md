# 🦠 Covid-19 India Analytics Dashboard

## Overview

The **Covid-19 India Analytics Dashboard** is an interactive Business Intelligence project developed using Tableau to analyze the Covid-19 pandemic data across India and generate meaningful insights into testing, vaccination, demographics, and state-wise case trends.

The project transforms raw Covid-19 data into interactive visualizations and dashboards that help understand the spread, testing efforts, vaccination progress, and demographic impact of the pandemic across Indian states.

The analysis covers the complete data analytics workflow, including data preparation, exploratory analysis, visualization, dashboard development, and business insight generation.

# 🎯 Business Objectives

The primary objectives of this Covid-19 Analytics project are:

- Analyze overall Covid-19 case statistics across India.
- Monitor confirmed, cured, and death cases over time.
- Analyze total deaths state-wise using a geographic map.
- Understand gender-wise distribution of Covid-19 cases.
- Analyze age group-wise distribution of cases.
- Compare state-wise testing details (negative, positive, total samples).
- Analyze first vs second dose vaccination progress.
- Understand vaccine-wise dose administration (Covishield, Covaxin, Sputnik V).
- Analyze ICMR testing lab distribution across states.
- Provide state-level and time-series case tracking.
- Support health authority decision-making through interactive dashboards.

---

# 📈 Dashboard Features

The Tableau dashboard contains a single comprehensive summary view with the following sections:

### 🗺️ Geographic Analysis

- Total deaths by state (choropleth map)
- State-wise Covid case trends (confirmed, deaths, cured) over time

### 🧪 Testing Analysis

- State-wise testing details: Negative, Positive, Total Samples
- ICMR testing lab count by state

### 👥 Demographic Analysis

- Gender-wise distribution (Male vs Female, excluding missing values)
- Age group-wise distribution (10-19, 20-29, 30-39, 40-49, 50-59, 60-69, Missing)

### 💉 Vaccination Analysis

- First vs Second dose administered
- Doses administered by vaccine type (Covishield, Covaxin, Sputnik V)

### 🎛️ Interactive Filters

Users can interact with the dashboard using filters such as:

- State / Union Territory
- Date range (case trend over time)
- Vaccine type
- Age group
- Gender

The dashboard tracks important Covid-19 metrics, including:

# 📊 Business Insights

The dashboard enables health authorities and analysts to understand:

- State-wise severity of the pandemic based on total deaths.
- Testing efficiency and positivity rate across states.
- Gender-based impact of Covid-19.
- Age groups most affected by Covid-19.
- Progress of vaccination in terms of first vs second dose coverage.
- Adoption trends of different vaccine types.
- Testing infrastructure capacity (ICMR labs) across states.
- Trends in confirmed cases, deaths, and recoveries over time.
